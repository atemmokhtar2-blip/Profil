# Hatem — Digital Architect

Personal portfolio for Hatem Mokhtar.

## Stack
- React 18
- Vite
- Lucide React
- CSS-first visual system
- Vercel-ready

## Local development

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```

The site is intentionally built without a backend so it can deploy directly to Vercel as a fast static frontend.
